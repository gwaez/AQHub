# secretary character pack

Technical id: `secretary` / app `AQWizard`.  
Display name is user-renamable in settings, not in this folder.

Default Arabic display name: السكرتيرة. English: Secretary.

PNG poses (~1254×1254 RGBA, transparent): idle, watch, think, speak, work, success, error, drag, sleep.  
The desktop wizard swaps `states.*.asset` when the state machine changes; host CSS still handles breathe/glance motion.
